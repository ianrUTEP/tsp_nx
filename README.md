Requirements:  
- Make your own venv, since part of git ignore
  - `python -m venv ./venvwin`
- Activate environment (modify for your system)
  - `source ./venvwin/bin/activate`
- Install requirements 
  - `python -m pip install -r ./requirements.txt`
